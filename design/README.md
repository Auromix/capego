# CapEgo 设计入口

CapEgo 面向开源开发者和研究者，首版提供个人或单个实验台能够复现的第一视角采集与本地数据集生产方案。从桌面物体操作开始，产出包含结构化双手动作、能够接入典型开源 WAM 训练的数据集。

产品定义、参考部署、采集保存、后处理及数据集生产的主要行为已逐项确认。接口、软硬件选型、质量指标和目标训练适配尚待设计；当前没有已完成的实现、训练接入验证或用户验收结果。

## 文档组织

`design/` 描述产品设计、系统架构、硬件、软件、数据及验证。Markdown 是设计来源。后续在相关决策形成后增加对应正文，不为填满目录提前选择实现。

| 主题 | 当前进展 | 后续应包含的内容 |
| --- | --- | --- |
| 产品 | 已确认使用者、参考场景、主流程和数据交付目标 | 完整交互、异常体验、具体成功条件 |
| 系统架构 | 同机接收、后处理和工作台；设备缓存补传；完整录制才能处理 | 接口、异常恢复、持久化确认和资源边界 |
| 硬件 | 头戴或胸戴方向，客户候选指标已记录 | 佩戴结构、传感器、同步、计算、供电与验证 |
| 软件 | 可视化工作台为主，命令行为进阶入口 | 操作行为、连接与记录管理、处理运行和扩展方式 |
| 数据 | 任务和操作两层分段、手部运动、物体和语义标注；处理及数据集版本固定 | 字段语义、质量、来源记录机制与训练适配 |
| 验证 | 实际 WAM 训练接入为交付要求 | 目标仓库、版本、数据与环境、测试条件和结果 |

## 状态使用

- **已确认**：产品方向或行为已经明确，不代表实现、验证和验收完成。
- **候选**：待比较和确认的输入或方案。
- **待设计**：尚未决定的具体条件或机制。
- **草案**：建议的设计或验证方法，仍需评审。
- **已实现、已验证、已验收**：具备对应证据时才使用。
