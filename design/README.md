# captureego 设计入口

captureego 面向自然双手操作的第一视角数据采集，以及后续本地处理、标注、数据治理和数据集生产。

当前只确认产品方向和能力范围，尚未完成具体产品行为、软硬件架构或实现设计。本文库不代表功能已经实现或通过验收。
