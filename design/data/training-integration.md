# WAM 训练接入要求

> 状态：实际接入开源 WAM 训练已确认为首版交付要求；目标工程、版本和具体验证方案待确认。当前没有已实现或已验证的训练适配器。

## 产品要求

captureego 导出的数据集应能实际接入典型开源 WAM 的训练流程。后续需要选择具名的开源训练仓库及版本，并明确所支持的训练任务和输入。通用数据格式可作为内部或中间表达，训练接入需要落实到具体工程。

本项目采集自然人类双手操作，后处理生成结构化人手动作。目标模型如何使用这些观测和动作，需要依据其训练入口定义，不能预设它们等同于任何机器人的关节或末端控制指令。

## 选择训练目标时需要核对

| 核对项 | 需要得到的答案 |
| --- | --- |
| 训练代码 | 哪个官方仓库、哪个版本提供需要的训练或微调入口，运行条件是什么 |
| 训练用途 | 学习哪类预测、动作条件或行为；与首版桌面自然双手数据是否匹配 |
| 观测 | 需要哪些视角、图像处理、时间关系、标定或状态字段 |
| 动作 | 动作主体、坐标系、单位、时间含义及有效性要求；是否需要额外映射 |
| 标注与样本 | 任务描述、片段边界、采样窗口、缺失数据和质量筛选的要求 |
| 数据集组织 | 目标数据读取器接受什么格式和元信息，训练与验证数据怎样组织 |
| 可复现条件 | 模型与依赖准备、训练配置、资源要求、输入版本和运行说明 |

目标数量、优先级和兼容范围尚未确定。选择有实际训练代码且输入语义与本项目数据匹配的目标，将是后续设计的一项明确决策。

## 建议的接入验证

以下是验证方案草案，不代表测试已经执行，也不替代后续按目标工程确定的验收条件。

1. 固定目标训练仓库的版本、模型与依赖、训练配置，以及 captureego 数据集版本和导出配置。
2. 使用真实参考场景采集、处理和检查得到的数据完成导出，检查观测、动作、时间关系及必要标注的语义和有效性。
3. 使用目标工程实际的数据读取器读取导出结果，构成其训练入口所需的有效批次。
4. 在约定环境中运行最小训练或微调过程，覆盖前向、损失计算和参数更新等该入口的实际训练步骤，记录结果。
5. 给出可重复执行的命令和配置，保留已验证范围、已知限制和输入版本，供其他开发者复现。

文件可以解析、形状可以拼接、数据可以预览，分别只证明对应环节可用。训练接入通过需要实际训练路径的运行证据；模型质量提升和机器人部署效果需要各自的实验目标与评估，尚未作为本轮产品结论确定。

训练验证可在另行确定的算力环境执行，Ubuntu 24.04 接收 PC 的要求不自动等于模型训练机要求。具体适配器、文件格式和动作映射将在目标选择后设计。

## 后续核查的一手资料

2026-09-22 初步查阅了以下官方训练资料。它们是后续选择目标时的对照入口，尚未选为 captureego 的首版适配对象，也没有证明自然人手数据已经兼容。

- [DreamZero 新本体数据与训练指南](https://github.com/dreamzero0/dreamzero/blob/main/docs/DATASET_TO_GEAR_AND_TRAIN.md)：提供 LeRobot v2 数据到 GEAR 元数据、模态配置及训练的流程；示例使用机器人的状态与动作，适配需核对实际字段语义。
- [Cosmos Policy ALOHA 训练指南](https://github.com/NVlabs/cosmos-policy/blob/main/ALOHA.md)：提供 ALOHA 数据准备与训练流程，可用于核查这类世界建模与策略训练的输入要求。

公开资料后续可能变化；进入适配设计时需固定实际代码版本，并核对对应的数据读取器和训练入口。
