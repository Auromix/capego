# 数据处理与数据集生产

产品范围已包含本地后处理与标注、局域网原始数据导出，以及接收算力设备上的数据治理与数据集生产。具体职责、部署方式和功能细节尚未确定。

## 已确认的使用关系

1. 人使用第一视角设备记录自然双手操作，并在本地保存数据。
2. 原始数据能够导出到同一局域网的另一台算力设备。
3. 算力设备能够用于数据治理和数据集生产。
4. 产品还应提供本地可用的后处理与标注能力；其运行位置、与导出的先后关系及具体内容待讨论。

这四点是产品关系，不定义程序模块、服务数量、传输协议或执行顺序约束。

## 后续需要定义的内容

| 主题 | 待讨论内容 |
| --- | --- |
| 后处理 | 需要完成哪些处理；例如时间整理、图像处理、片段处理或轨迹估计，均未确定为必选 |
| 标注 | 标注什么；任务文本、操作片段、结果、手部或物体等对象如何选择 |
| 人工与自动协作 | 哪些步骤自动运行，哪些需要人工修改或复核，如何表达不确定性 |
| 导入与治理 | 如何组织记录、筛选质量、定位问题、管理处理版本与数据来源 |
| 数据集生产 | 样本和片段如何定义，选择哪些数据，怎样组织训练与验证集合 |
| 数据导出 | 原始导出与训练导出分别交付什么，如何按目标管线定义格式与版本 |
| 本地运行 | 是否必须完全断网可用；模型、依赖、算力和存储的准备条件 |
| 可追溯性 | 原始记录、处理结果、人工标注和导出样本之间如何建立联系 |

## 当前不作推断

- 本地后处理与标注不自动绑定到穿戴设备，也未绑定特定算力平台。
- 数据治理不自动包含企业级账号、权限、多租户或多人协作。
- 数据集生产不自动表示已支持 LeRobot、RLDS 或任何特定 WAM 的训练入口。
- 轨迹估计与机器人动作重定向尚未确定为首版交付。
