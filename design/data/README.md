# 数据处理与数据集生产

原始数据在录制期间持续保存到同一局域网的 Ubuntu 24.04 PC。用户选择已结束且完整落盘的一条或多条采集记录并启动后，同一台 PC 执行自动处理与标注。工作台支持问题检查、少量修正及跨采集生产固定数据集版本。

## 尚待定义的数据契约

- 原始视频、IMU、标定、时间戳、分块索引及完整性记录的精确表达。
- 21 点的命名与索引、坐标轴约定、单位、频率、质量字段和精度要求，以及相机轨迹与坐标转换的表示。
- 任务与操作边界、物体位置和身份、语义标签及不确定性的字段。
- 自动质检阈值、人工检查记录、修正历史和不可人工豁免的问题。
- 数据集内容固定、来源引用、清理保护、去重及训练与验证集划分。
- 具名目标训练仓库、版本、动作语义、适配器和验证条件。

当前已进入软件原型阶段。已完成处理、检查、快照与导出链路，并用模拟 ego 数据验证固定版本 EgoWAM 的缩小配置联合训练入口；真实三维手部估计和发布版训练配置仍未验证。详见[验证记录](../validation/2026-09-24-software.md)。
