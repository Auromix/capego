# 数据处理与数据集生产

产品已经确定自动标注、人工以检查为主，以及跨采集和处理批次生产命名数据集版本。原始记录在采集期间持续保存到同一局域网的 Ubuntu 24.04 PC；用户选批并启动后，后处理在本地计算环境自动执行。完整使用关系见[产品定义](../product/scope.md)和[使用流程](../product/workflow.md)。

## 数据内容与用途

| 内容 | 已确认的用途 | 后续需要定义的细节 |
| --- | --- | --- |
| 原始观测 | 保存视频、IMU、标定信息等，作为处理和检查的基础 | 格式、时间语义、标定组织、传输及落盘完整性 |
| 任务与片段 | 由后处理识别任务、划分操作片段和生成相关描述 | 任务类别、边界规则、重叠关系与不确定性表达 |
| 双手动作 | 产出结构化双手动作，覆盖所讨论的三维关键点和手腕位置、姿态等类型 | 精确字段、坐标系、单位、频率、质量和可用范围 |
| 质量与检查 | 表达估计置信度、缺失和问题；保留人工复核记录 | 自动规则、问题优先级、抽查与修正操作 |
| 数据集版本 | 跨记录、跨批次选择内容并保存命名版本，重复导出相同内容 | 版本固定范围、筛选规则、来源关系和导出配置 |
| 训练导出 | 实际接入典型开源 WAM 训练流程 | 目标仓库、版本、输入语义、适配与运行验证 |

## 自动与人工的分工

自动处理承担任务识别、片段划分、结构化双手动作提取、相关标注和质量检查。系统收到新数据后等待用户发起处理；用户选定一批记录后，一次启动完整流程。

人工主要检查系统提示的问题片段，并抽查其他结果。少量纠正与补充属于产品范围；具体是否提供文字编辑、片段边界调整或三维动作编辑，需要继续明确。自动检查结果和人工复核记录分别保留，未复核的数据不记录成已人工确认。

## 数据集与训练目标

一次采集可以产生多个任务片段，一次处理批次也不限定为一个最终数据集。用户可以跨记录、跨批次筛选和组合内容，形成命名版本。版本需要能重复导出相同内容，具体固定范围及来源管理待设计。

目标模型的数据要求将影响动作定义、片段组织和导出适配。用户已明确要求实际训练接入，验证边界见[WAM 训练接入要求](training-integration.md)。目前尚未选定目标模型，也没有可声明已支持的训练入口。
