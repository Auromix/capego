## 数据确实进入目标训练

目标源码：[GaTech-RL2/EgoWAM](https://github.com/GaTech-RL2/EgoWAM/tree/c87617fe37a6ed6a951e6b176ad552200c425c93)，固定提交 `c87617fe37a6ed6a951e6b176ad552200c425c93`。验证脚本拒绝其他提交或修改过的目标源码。

执行链：CapEgo HTTP 模拟采集 → 处理与快照 → Zarr → 官方 `Human.get_keymap`、`Human.get_transform_list`、`ZarrDataset` → 官方 `HPTModel.compute_loss` → loss.backward → AdamW.step。

macOS CPU 实测：

| 项目 | 结果 |
| --- | --- |
| 数据来源 | synthetic，机器人样本 0 |
| batch / action shape | 4 / `[4,4,12]` |
| 未来图像目标 | 从实际导出图像池化得到 `[4,1,192]` |
| 参数数量 | 60,780 |

| 动作 / 世界预测分支 | 均产生非零 loss，梯度有限 |

这验证了真实目标源码中的数据使用、世界/动作损失、反向传播和参数更新。使用缩小的 HPT、官方 MLP stem/Transformer head 与池化 RGB，不下载预训练权重，不等价于论文/发布版配置、模型质量或 48GB GPU 训练验收。

导出将参考相机位姿映射到 `obs_head_pose`，将左右腕轨迹映射到人类 `obs_ee_pose`。这是明确的观察轨迹代理，不是机器人命令，也不声称与 Aria 的掌部坐标定义完全相同。`aria_bimanual` 是复用目标 Human loader 的兼容标签；metadata 同时记录真实来源 `capego_ego` 和 synthetic 标记，不能据此声称数据由 Aria 硬件采集。

## 本地 VLM 推理

实际下载并离线运行 `Qwen/Qwen2.5-VL-3B-Instruct` 固定模型版本 `66285546d2b821cf421d4f5eb2576359d3770cd3`，设备为当前 Mac 的 MPS。输入为 2 秒合成 RGB 采集中的 4 个采样时刻。

首次自由 JSON 生成漏字段、错单位，被契约拒绝。最终使用 [LM Format Enforcer](https://github.com/noamgat/lm-format-enforcer) 限制 JSON 结构，再单独校验时间范围和父子关系；得到可解析的任务/操作草案，所有结果保留 needs_review，操作保留 undetermined。这验证了真实模型推理及接口通路，**不等于真实场景识别质量通过**。模型原始响应只保存在本地对应 processing 目录，未提交 Git。

ID 和父子关系由适配器生成，语义草案不冒充物体跟踪或 3D 结果。已下载的模型放在 Git 忽略的 `models/`，后续推理使用 local_files_only、不启用 remote code。

小模型在合成示意图上出现过泛化描述、重复语句和手别判断不可靠。最终限制每次最多 2 个任务、每任务 4 个操作和每条 300 字符，降低重复输出和审阅负担；这只是当前采样原型的资源边界，不是长录制完整自动分段能力。全部语义草案仍须检查，不能宣称已经实现少量人工即可得到高质量标注。

## 未完成的真实世界验证

- 没有实体设备：双目曝光同步、IMU 硬同步、1–2 ms 指标、1080p/60 FPS 吞吐、无线稳定性、功耗与发热尚未测试。当前 JPEG/JSON 原型包不等于生产 H.265/AV1 编码实现。
- 三维手部和相机轨迹只有明确标记的合成测试后端，尚无经过真实标定验证的估计器；真实/回放数据不能调用 synthetic 后端冒充真实结果。
- VLM 已在合成画面上运行，真实操作场景的语义、短动作覆盖、左右手识别与分段准确性尚未验证。
- 无影客户端能够显示云电脑资源卡，但实际桌面窗口白屏；官方 Web 入口需要协议确认才能继续登录。目前未取得可执行终端，没有在该云电脑上运行命令或测试 GPU。
- 已核查本机没有可用云管理 CLI 凭据。桌面登录账号不等于云管理 API/RAM 授权，桌面 ID 也不等于 SSH 地址。本轮没有修改网络、安全组或开放公网端口。

## 已知原型边界

- 数据包、帧解码和校验以可检查、可测试为先，未做长时高吞吐优化；部分读取会枚举整条采集索引。
- 接收与处理可独立执行；单实例默认单处理 worker。中断处理不自动续跑，重新提交会创建新版本。
- Zarr 固定为 3.1.5，使用目标源码同款 VariableLengthBytes；该类型有上游实验性规范警告，跨库互读不作保证。
- 没有 LICENSE，公开仓库不等于已授予开源许可证；许可证选择仍保留为产品决策。
